# Zimbabwe Women's Population Growth and Contributing Reproductive Health Factors Analysis

## Project Overview

This project explores women's Population trends in Zimbabwe using reproductive health indicators covering several decades.

The analysis focuses on fertility patterns, contraceptive use, teenage pregnancy, age at first marriage and access to healthcare.

The objective is to identify trends over time and differences in reproductive health outcomes across wealth groups.

## Research Questions

This project investigates the following questions:

1. How has Zimbabwe's female population changed over time?
2. How have fertility rates changed across decades?
3. How does fertility differ across wealth groups?
4. How has contraceptive use changed over time?
5. Is contraceptive use associated with fertility differences across wealth groups?
6. How has access to healthcare changed over time?
7. How does age at first marriage differ across wealth groups?
8. How does teenage pregnancy vary across wealth groups?

## Dataset

The dataset contains 10,535 observations and 6 columns, covering 604 health indicators for Zimbabwe.

The dataset includes:
- Country Name
- Country ISO3
- Year
- Indicator Name
- Indicator Code
- Value

The analysis uses selected indicators relevant to women's reproductive health.

### Data Source

The dataset was downloaded from ZimData and is sourced from the World Bank.

- Dataset: Zimbabwe Health Indicators
- Coverage: 1960–2025
- Format: CSV
- Download: https://www.zimdata.org/datasets/zimbabwe-health

Key Findings
- Zimbabwe's female population increased substantially over the period analysed.
- Fertility rates differed considerably across wealth groups.
- Wealthier groups generally reported higher contraceptive use and lower fertility rates.
- Women in poorer wealth groups experienced greater difficulties accessing healthcare facilities.
- Teenage pregnancy and motherhood were considerably more common among poorer wealth groups.
- Women in wealthier groups generally married later.

Limitations
- The analysis focuses on selected health indicators.
- Direct education indicators were not available in the dataset.
- Some indicators cover different periods.
- The findings identify associations and trends rather than proving causation.
Conclusion
The analysis highlights significant differences in women's reproductive health outcomes across wealth groups in Zimbabwe.

The findings demonstrate the importance of considering socioeconomic inequalities when examining fertility, contraceptive use, teenage pregnancy and access to healthcare.
