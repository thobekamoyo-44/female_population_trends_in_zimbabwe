# Project Overview

## Project Title
Zimbabwe Women's Health Analysis

## Background

Women's reproductive health is an important part of public health. Understanding changes in fertility, contraceptive use, teenage pregnancy and access to healthcare can help identify health trends and inequalities.

This project explores selected women's health indicators in Zimbabwe across several decades, with particular attention to differences between wealth groups.

## Project Objectives

The objectives of this project are to:

1. Examine changes in Zimbabwe's female population.
2. Analyse fertility trends across decades.
3. Compare fertility rates across wealth groups.
4. Investigate contraceptive use patterns.
5. Explore differences in access to healthcare.
6. Examine age at first marriage and teenage pregnancy.
7. Identify patterns and inequalities in reproductive health outcomes.

## Dataset Description

The dataset contains 10,535 observations and 6 columns, covering 604 health indicators for Zimbabwe.

The observations cover the period 1960–2025.

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Scope

The analysis focuses on selected indicators related to women's reproductive health. It uses descriptive statistics, comparisons across wealth groups and visualisations to identify patterns and trends.

The project does not attempt to establish causal relationships.
